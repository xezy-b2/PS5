Synchroniser avec ton imprimante

Un petit programme sur ton Mac lit l'AMS sur ton réseau local, en lecture seule. Ton imprimante reste en mode normal : Bambu Handy et le cloud continuent de marcher.

  1. Télécharge le pont AMSPont AMS pour Mac (.zip) ou le script Python (Windows / Linux)
  2. Installe-le, une seule foisDouble-clique sur le .zip, puis fais un clic droit → Ouvrir sur « Installer le pont AMS ». Entre l'adresse IP et le code d'accès (Réglages → Réseau de l'imprimante) et le numéro de série (Réglages → Appareil). Si macOS demande l'accès au réseau local, accepte.
  3. C'est toutLe pont tourne ensuite en arrière-plan et démarre tout seul avec ton Mac, aucune fenêtre à garder ouverte. Clique sur « Synchroniser depuis l'imprimante » quand tu veux ; si le navigateur demande l'accès au réseau local, autorise-le.

Pour le retirer : « Désinstaller le pont AMS », dans le même .zip.
